# CreateAddon

A Minecraft 1.21.1 NeoForge addon for Create 6.

CreateAddon expands Create with kinetic machinery, laboratory glassware and fluids, plus custom compressing, sequenced-assembly, and sieving recipes.

## Compatibility

- Minecraft 1.21.1
- NeoForge
- Create 6.0.9 through 6.0.x

## Development

Use JDK 21, then run:

```sh
./gradlew build
```

Local Gradle caches, IDE settings, and Minecraft test-world output are intentionally ignored by Git.
